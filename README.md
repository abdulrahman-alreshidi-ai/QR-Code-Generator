# QR Code Generator

A Python application that generates QR codes from text or URLs.

## Features

- Generate QR Codes
- Save as PNG Image
- Supports URLs
- Supports Plain Text

## Technologies

- Python 3
- qrcode
- Pillow

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
